# Data notes

This folder intentionally contains **aggregate output only**.

## Source

Download the public IBM Telco Customer Churn CSV from the [IBM source repository](https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv) when reproducing the analysis. Save it locally as `data/Telco-Customer-Churn.csv` or pass its location with `--input`.

The raw CSV is excluded from version control by `.gitignore`. It is not needed to review the published findings, and keeping it out of the repository avoids redistributing customer-level records.

## Published file

`aggregate-findings.json` is generated by `analysis/churn_analysis.py`. It includes only the validation summary, cohort-level rates, interpretation, and limitations used in the portfolio.
